# Contributing

Thanks for helping keep this list useful.

- One tool per pull request, titled `Add tool-name`.
- The tool must be about running, delivering, updating or monitoring ML models on devices outside the data center.
- It should be actively maintained (a release or commit in the last 12 months), and not archived.
- Use the format `- [Name](link) - Short description ending with a period.` Keep the description factual, not marketing.
- Keep each section in alphabetical order.
- Commercial products are fine if they are useful on their own; say so plainly in the description if there is no free tier.
- Authors are welcome to add their own tools. Please say so in the pull request.
